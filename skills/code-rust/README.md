# Rust Code Skill

This skill helps developers write idiomatic, production-ready Rust code. It provides practical guidance for environment setup, project structure and configuration, ownership and borrowing, API design, error handling, async programming, testing, performance, safety, and Cargo, Clippy, and Rustfmt workflows.

The main references include:

- `SKILL.md` - Skill overview and usage scope
- `env-setup.md` - Rust development environment setup
- `configuration.md` - Repository and project configuration
- `project-structure.md` - Recommended Rust project layout
- `code-rules.md` - Categorized Rust coding best practices
- `test.md` - Testing guidance
- `rules/` - Detailed rule documents with examples
